O que é o Revelê

O Revelê é uma ferramenta gratuita para criar um bolão de chá revelação online: os convidados palpitam menino ou menina (e o nome, a data e o peso do bebê) a partir de um único link, o placar se atualiza sozinho e, no grande dia, você revela o resultado com uma animação em tela cheia e o ranking de quem acertou. Criar e coletar palpites é grátis; você só paga uma vez, se quiser, para desbloquear a revelação completa sem marca d'água.
